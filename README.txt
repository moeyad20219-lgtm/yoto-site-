YOTO WEBSITE — FIRST VERSION

Files:
- index.html: page content
- style.css: responsive design
- script.js: mobile menu, product request notice, current year
- assets/yoto-hero.png: generated visual asset

HOW TO TEST:
1. Extract the ZIP file.
2. Open index.html in Chrome or Edge.
3. Click navigation, Discord links, and the product request button.

HOW TO PUBLISH FREE WITH GITHUB PAGES:
1. Sign in or create an account at https://github.com/
2. Create a new repository named yoto-site (Public).
3. Upload index.html, style.css, script.js, and the assets folder (with yoto-hero.png).
   Keep the exact folder/file names and structure.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes; the Pages section will show the public website URL.

IMPORTANT:
- This is a static front-end demo. It has no real user accounts, Discord OAuth login,
  admin dashboard, payment checkout, or automated file delivery.
- The product request button opens the Discord invite; arrange payment and delivery manually
  until you connect a secure payment/provider and backend.
- The Discord invite is configured in index.html and script.js. Replace it if needed.
- The font loads from Google Fonts; the site remains readable if it cannot load.
